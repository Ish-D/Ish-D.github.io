## Neural Networks
[[tab]] The foundation of mostly all modern machine learning is the neural network. We care about them largely because of the [[cite(https://en.wikipedia.org/wiki/Universal_approximation_theorem)]]{Universal Approximation Theorum} which says that neural networks of the correct size and shape can be used to approximate any continuous function to any desired degree of accuracy.  [[note(right, type: relative, orient:horizontal)]]{}{In reality it is heavily debated what LLMs actually "learn". Many argue they are 'stochastic parrots' that convincingly interpolate between training data to spit out believeable responses. Others believe that in approximating the underlying distribution of language, models learn the rules of the world that generated it.} The idea in LLMs is that by training sufficiently large networks to learn the underlying distribution of language, we are training in a general model of the world. 

[[bigbreak]]
### The Neuron
[[tab]] Neural networks, despite the lofty goals, are surprisingly simple at their core. A single neuron takes an input vector $x = [x_1, x_2,..., x_n]^T$, contains a trained weight vector, $w = [w_1, w_2, ... , w_n]^T$, and trained bias scalar $b$. All each neuron does is compute a linear combination of the inputs: $z = w^Tx + b$. This final value is then put through a non-linear activation function g(z). 

[[bigbreak]]
### The Layer
[[tab]] These neurons are then organized into layers. A layer is simply a collection of independant neurons that together, project our input data into a higher dimension. If we have n features, our input vector $x$ lives in $\mathbb{R}^n$. Then for a layer with $m$ neurons, each will have a weight vector $w \in \mathbb{R}^n$, which we can express as a weight matrix $W \in R^{m \times n}$ (simply all the weights stacked on top of each other).  We can similarly stack each neuron's bias scalars to form our bias vector $b$. Our output vector for the entire layer is now $z = Wx + b$. Overall, the layer performs an affine transformation $T(x): \mathbb{R}^n  \rightarrow \mathbb{R}^m$.
[[break]]
[[tab]] You may have already recognized that if we stopped here, and chained layers together like this, we wouldn't actually be able to learn much. We would be left with a series of affine transformations on our input data. The product of two affine transformation matrices is also affine, meaning we would simply be doing a series of scales, rotations, shears, and translations to our input vector. No matter how many layers we have, they would all collapse into a single affine transformation and we could only learn linear functions! This is why we introduce activation functions: we pass the affine output through a non-linear function that "folds" the vector space into complex shapes. We are then left with many linear segments (one per neuron) that are used to approximate any arbitrary smooth multi-dimensioned function.
[[note(right, type:relative, orient:horizontal)]]{}{Visualization shows an example of how with more separating planes, we can better fit the surface of complex distributions. Try changing the number of neurons, or enter a new function to fit.}
[[viz(type: neuron-approx, height: 380, width: 320, align: center)]]
[[tab]]There are then three types of layers.We start with some vector that directly represents whatever data we feed the network, and put it through an input layer which compresses the vector down to a dense latent space. 
[[break]]
[[tab]]There is then a series of "hidden" layers (hidden because they do not directly interface with the real-world data, and because they are used to learn higher dimensional relationships) that will project their input layers into a higher dimensional space.  [[note(left, type: relative, orient:horizontal)]]{}{For a concrete example here, imagine that we are working with a "dictionary" of 50,000 words that the model recognizes. Then every single word is encoded as a unique vector in $\mathbb{R}^{50,000}. $ The input layer will take the vector corresponding to some word we feed it, and project it into a continuous latent vector space, e.g. $\mathbb{R}^{4096}$. Every hidden layer will then expand its input from $\mathbb{R}^{4096}$ to e.g. $\mathbb{R}^{16384}$. After it applies its activation function, it will then recompress back to $\mathbb{R}^{4096}$ , add it to the input vector, and pass it on to the next layer. Finally, the output layer will take our $\mathbb{R}^{4096}$ vector that has been enriched by the hidden layers, and project it to our original $\mathbb{R}^{50,000}$.}  The idea here is that we are going from a dense lower-dimensional representation of information into a much sparser high-dimensional space, which yields us a few benefits. For one, we are better able to isolate features; we have many more neurons to work with that activate under more specific circumstances which creates sparsity in our actviations and more unique combinations. Our many basis vectors that were previously dependant have a much better chance at being independant, giving operations the room to act on more specialized tracts of neurons. 
[[break]]
[[tab]] Finally, we have the output layer. This will take the vector produced by the final input layer and "undo" the transformation done by the input layer;  project this new compressed vector down into our original vector space. 

[[bigbreak]]
### The Network
[[tab]] A neural network simply consists of an input layer, hidden layer, and output layer. A deep neural network is a network that contains 2 or more hidden layers. Much of the power of neural networks in modern machine learning comes from chaining layers together in these deep networks. In theory you can learn any underlying distribution in a neural network with a single hidden layer with enough neurons. In practice we see that using a single large layer ends up brute-forcing the distribution, each neuron represents some highly localized feature in what we are trying to represent. In other words, the network's ability to create distinct linear segments grows linearly, for a function that is 10x as complex, we need 10x the number of neurons.
[[break]]
[[note(right, type:relative, orient:horizontal)]]{}{One nice way to think about the effects of having multiple layers is through image processing. If we are training a network to recognize faces, the first layer may implicitly learn to detect edges, the second curves and corners, the third features of the face, and a final layer specific faces. If we only had one layer, we would be expecting the single hidden layer to learn the weights to go from pixel values to the abstract concept of a face.}
[[tab]]  This is why we use many layers. We've established that a single layer acts as some non-linear function, multiple layers chained together acts as multiple composed functions. This allows for each layer to learn more abstract concepts rather than relying on a single layer to make the leap from input to output. 
[[break]]
[[tab]] I also want to take some time to talk about what our input data looks like as it goes through a network. If we think about processing an image of a face, the same image shifted by a few pixels may look completely different when comparing them pixel by pixel in the input space.  In other words, there is no real meaning represented by the vectors in this place, they are chaotic.When the raw data passes through the first hidden layer, we know that it projects it into a latent space. These latent spaces are what is learned when we talk about training a neural network. Every layer's weights and biases evolve through the training process to learn various aspects of the training data.  Now, in a well-trained network, axes in the latent space might represent more meaningful concepts: for example when processing text some axis may represent "negative tone" or "plurality". 
[[break]]
[[tab]] One of the most important qualities of these learned latent spaces is that we can perform linear algebra operations on concepts. One of the most famous examples is that given vectors for different words in this space, we can expect the following to be true: $v_{king} - v_{man} + v_{woman} \approx v_{queen}$. We can also calculate the distance between vectors to gauge semantic similarity, we expect king and queen to be roughly next to eachother in space, separated by the same distance that man and woman are. 
[[break]]
[[note(left, type:relative, orient:horizontal)]]{}{Going back to the image processing example,  in our initial data there is no nice way to tell apart dog from cat but we know that there are definitive concepts that make dogs dogs and cats cats. As we go through the hidden layers, the goal of the network is to take our initially meaningless space and "untangle" it till all dog-concepts are clustered together, and all cat-concepts are clustered together. }
[[tab]] We touched on the idea that our original input space is incredibly noisy & chaotic, there are no real noticeable relationships between any vectors. Despite this, all of our data does actually live on some smooth surface (a manifold), there is a fundamental reality that dictates the similarities and differences between concepts. The ultimate goal of all of our layers is to progressively transform this manifold until we end up in a vector space where all of these concepts on the manifold are clustered together with meaningful relationships between them. This manifold exists regardless of the space we are in, but different layers project it into new spaces that allow us to look at it through different lenses. The final output layer can then simply draw a separating hyperplane on our nicely untanged manifold to make its final classification or prediction. 

[[bigbreak]]
### Training a Network
[[note(right, type:relative, orient:horizontal)]]{}{We define our own loss function for the distribution we are training the data to learn. All the loss function does is find the distance between where the data actually landed in our final latent space, and where it should have landed.}
[[tab]] Before we can do anything useful with a network, we need to train it. All of the neurons are initialized with completely random weights and biases. Geometrically, our network is effectively randomly stretching and folding our input data, with our inputs ending up at entirely arbitrary positions in the final latent space. To train a network, we feed it many examples of inputs where we already know the outputs, the data will flow through the layers and make a final prediction. We use a mathematical loss function to calculate how far from reality that prediction was.
[[break]]
[[tab]] Once the network knows how wrong its guess is, it uses an algorithm called gradient descent to adjust the weights in the right direction. It does this with backpropagation: going backwards through every layer of the network and calculating by how much it needs to tweak its weights and biases. Through many of these slight adjustments, the network iteratively remodels the mesh formed by all of the piecewise segments represented by the hidden layers to fit the geometry of the underlying function. The visual below can give you can idea of how over many iterations, we can slowly tweak our random weights to fit an arbitary function.
[[viz(type: gradient-descent, height: 380, width: 320, align: center)]]
[[tab]] There is a lot of nuance and literature in training that I am glossing over here for the sake of brevity. To learn more about the training process and how neural networks work in general, I highly recommend taking a look at Andrej Karpathy's [[cite(https://karpathy.ai/zero-to-hero.html)]]{Neural Networks: Zero to Hero}. He goes over building neural networks from scratch, with lots of valuable intuition about what each step in the process is actually doing. 
[[bigbreak]]
### Inferring a Network
[[tab]] Once training is complete, we can lock the weights and biases of the network in place (given faith that they have actually learned the desired distribution) and use them for inference. Inference just means giving the network new data to make guesses based off what it knows of the distribution it was trained off of.
[[break]]
[[tab]] Compared to training, inference is much more straightforward. When we talked about the layers of a network we saw that all of the work for a single layer is simply $z = Wx + b$ followed by an activation function. Given an input vector, we do our sequence of matrix multiplications, adding biases, and computing activation functions until we reach the output layer. [[note(left, type:relative, orient:horizontal)]]{}{One way to look at this is that discriminative machine learnign will compute "slices" of the manifold in latent space at training time, and during inference we just have to find where among the slices our data belongs. For generative inference, we take each part of the input and "walk" across the manifold to find the portion that is most likely to follow the input.} For discriminative inference (tasks like classification), all the output layer has to do is look at which side of the deciding hyperplane in the final latent space that the data point lands on to spit out a final prediction. For generative inference (things like LLMs or image models), a modern architecture like transformers will transforms the input vector into a final vector in the latent space. The output layer then considers the distance between that vector and every other known vector in a known dictionary of words. For example given the input "the monkey ate the ", we might find that the final vector is a 90% match to "banana", a 5% match to "apple" and a 0.0001% match to car. It will then take "banana", add it back to the input, and run the whole process again so that next time we walk to a new point on the manifold to generate coherent text. 

[[bigbreak]]
##  Transformers
 [[note(right, type:relative, orient:horizontal)]]{}{Fun fact, the GPT in ChatGPT stands for "generative pre-trained transformer". Generative in this case meaning it is used to generate text and pre-trained meaning it uses the gradient descent based weight-adjusting scheme we described earlier.}
[[tab]] Given you should now have some intuition around the fundamental concepts of neural networks, lets move onto the basis of LLMs (and most other modern parts of machine learning): the Transformer. Transformers were introduced in Google's seminal 2017 paper [[cite(https://arxiv.org/abs/1706.03762)]]{Attention is All you Need} (Vaswani et al.).

[[bigbreak]]
### Context, Ambiguity, and Attention
[[tab]] One of the core problems with vanilla neural networks as described above is that every word has a single fixed position in latent space. No matter what came before it, if the network sees "bark" it will always assign it the exact same vector. This is unlike real language where meaning is highly dependant on the context; bark means something very different depending on if we're talking about a dog versus a tree. This is the problem solved by what is known as *Attention*, introduced in the 2014 paper [[cite(https://arxiv.org/pdf/1409.0473)]]{Neural Machine Translation by Jointly Learning to Align and Translate.} (Bahdanau et al.).
[[break]]
[[tab]] Attention solves this problem by having words in a sentence look at every other word, evaluate their relationship, and adjust their own meaning based off of their neighbors. The vector for "bark" will always start off at the same fixed position but will move in space towards different concepts depending on what it sees around it, so "bark" somewhere in a sentence after "tree" means something very different from "bark" somewhere in a sentence after "dog" or "peppermint". Concretely, Transformers implement this by taking every word's starting vector and multiply it by three different weight matrices to create three new vector for each word: the query (Q), the key (K), and the value (V).The query represents what the current word is "looking for", the word "bark" may project a vector that says "are there any tree or dog related words around me?".  [[note(left, type:relative, orient:horizontal)]]{}{If you are struggling to reason about how the Q & K vectors can represent so many different concepts, it can help to remember that we are working in high dimensional spaces like our $\mathbb{R}^{4096}$ example from earlier. So if axes #5 represents noun-ness, axis #500 represents roughness, and #838 represents being a loud sound, we might see that the key vector for "bark" has spikes on those axes.} The key represents what the current word is, "bark" may signal "I am a noun", "I am am object that can be rough", and "I am a loud action/sound" simultaneously.  Finally, the key vector is the pure meaning of the word that gets trasmitted to other words, its job is to move other vectors to more context aware locations in latent space.
[[break]]
[[tab]] What makes this system so powerful is that it decouples what about words makes them a good match for other words, and what they mean. When we see a sentence like "the fluffy dog barked",  "fluffy" broadcasts "I am an adjective texture, and I am looking for an animal or maybe furniture noun". But the meaning of fluffy doesn't really matter in that matching process. 
[[break]]
[[tab]] The actual attention computation is very simple, each word in the sequence will do a dot product between its own query vector, and every other word's key vectors. Q and K pointing in the same direction implies semantic similarity so their dot products will be high, if they are completely unrelated then they will be orthogonal in space and their dot products will be zero. Once we have done this computation for a single word, we put all of the vectors through a softmax, a computation that transforms all of them into values summing to 1. This gives us our attention matrix. Going back to the fluffy dog, if we are computing attention scores for the word "barked" we might see something like:
[[break]]
| Word    | Score | Rationale |
| :--- | :------ | :---- |
| The        |   0.02   | Not necessary to "barked" for meaning |
| fluffy    |   0.08   | Might give slight reasoning to type of thing that barked, but not core to meaning. |
| dog    |  0.65   | Tells "barked" that it is a dog that is barking, the core of what we were looking for. |
| barked |  0.24   | Self-attention, make sure barked remembers some of its baseline meaning. |
| . |  0.01   | Similar to "The", simply a structural word for "barked"|
[[note(right, type:relative, orient:horizontal)]]{}{In practice we would just take all the words in our sequence, and create a matrix of all of their Q and K vectors stacked on top of eachother to get a query matrix and a key matrix. Multiplying these together gets us our final matrix of attentions cors.}
Remember that this is only the attention computation for the word "barked" we would also do this for every other word in the sentence.  For each word, we then get a new context vector with the simple calculation $\vec{x}_{context} = \sum score_i \times V_i$. In other words, it is just a linear combination of each value vector and its corresponding attention score. This should make intuitive sense, if we determine that "dog" is really important to the meaning of "barked" then obviously we should weigh its value contribution to "barked"'s meaning more than "fluffy".The next step in this computation is to re-add the original vector to the new context vector: $\vec{x}_{new} = \vec{x}_{original} + \vec{x}_{context}$. This is called a residual connection, it makes sure that we are adding context to the original vector, enriching its meaning for the network, not fully replacing it.Finally, we do a normalization step to our new vectors to make sure they do not grow boundlessly as we enrich them with context.

[[bigbreak]]
### Positional Encoding
[[tab]]  There is one glaring issue with attention that we need to address before we can move on. We know words "attend" to other words to try and gain context, but the simple dot product we use to calculate similarity does not know anything about words positions. The sentences "The dog bit the man" and "The man bit the dog" look mathematically identical to attention.
[[break]]
[[tab]] To fix this, we use positional encodings. Before any word is put through any part of the model we stamp it with a position so that each vector has a unique signature the model can learn to recognize where in the sequence each word belongs in. This is as simple as adding on a position vector to each word's original vector: $\vec{x}_{input} = \vec{x}_{word} + \vec{x}_{position}$.
[[break]]
[[tab]] This ensures that the model is also able to learn relationships between words and types of words during training.  It should be able to learn that the query for "I am looking for a noun" is only really relevant for keys that say "I am a noun" in certain positions, not equally across the entire input sequence. It also means that it can learn how much the distance between two words matter, if we have the word "blanket" much earlier in our input and then we see "the fluffy dog", we shouldn't attribute fluffy equally to dog and blanket. We should know that fluffy probably doesn't attend to blanket because of how far back it is.
[[break]]
[[tab]] In practice one way that many models generate these embeddings is through [[cite(https://arxiv.org/pdf/2104.09864)]]{Rotary Positional Embeddings (RoPE)} (Su et al.). What RoPE does is instead of adding a static vector at the start, we rotate all of our vectors during the attention computation. We have some rotation amount $\theta$, and the word at position $n$ gets rotated by $\theta n$. This works perfectly for attention because scores are calculated with a dot product, which depends on the angle between two vectors. With RoPE, the relative angles between any two words at fixed distances will be the same, and the further away two words are the more they will be rotated relative to eachother so the lower their attention score will be. In short, Attention Score $\propto \cos(\theta_m - \theta_n)$.

[[bigbreak]]
### Making Meaning from Context
[[tab]] At this point, we have a vector for each word in our sequence that is the normalized sum of each word's original vector plus some context that is meant to enrich it based off of the meaning of surrounding words. Now, every single word's vector is put through a feed-forward neural network. There is no communication here, every vector is put through the exact same network independantly. 
[[break]]
[[tab]]
When our context-enriched vector for "barked" comes out of the attention mechanism, it has absorbed the geometric position of "dog" but the vector "barked + dog" doesn't really mean anything, it is just a coordinate in space. It is up to the network to say "this coordinate corresponds to the sound that a small house-pet canine makes". There is nothing special about this network compared to the ones we talked about in the previous sections, it just has a weight matrix that was trained to extract meaning from vectors produced by attention. 
[[break]]
[[tab]] Finally, similarly to the end of the attention stage,  we do a residual connection followed by a normalization. We add the input to the feed-forward network to the output vector it produces to make sure we do not completely lose the original context we started with, and we normalize that final vector to make sure it lives in a range that following layers recognize.

[[bigbreak]]
### Generating a Token
[[tab]] The sequence we have described above, Attention $\rightarrow$ Residual & Normalize $\rightarrow$ Feed-Forward Network $\rightarrow$ Residual & Normalize, represents a single transformer block/layer. [[note(left, type:relative, orient:horizontal)]]{}{Theere is a field called mechanistic interpretability that focuses on trying to figure out what exactly it is that models learn, and where they learn these things. There is a lot of interesting work being done on things like [[cite(https://dnhkng.github.io/posts/rys/)]]{figuring out what different layers in a pre-trained model do} or [[cite(https://www.anthropic.com/research/emotion-concepts-function)]]{mapping neuron activations to human emotions.}} You can think of these layers as having a similar relationship to the hidden layers within a single neural network that we discussed earlier. Earlier layers may learn things like parts of speech or syntax and grammer, middle layers may shift to semantics and longer ranged relationships, and later layers may represent abstract task-specific concepts. It is important to note that none of this is explicitly wired into the model; we never say "layers 1-10 learn grammer, 11-20 learn semantics, and layers 21-30 learn niche concepts". All of these relationships are implicitly created during training. 
[[break]]
[[tab]] After every single word in our input go through the sequence of transformer blocks, progressively gaining enriched context and meaning through different relationships with other words in the sequence, we are ready to generate the next word. After the final transformer block, we actually only care about the very last word in our input. By this point, the vector representing the word is meant to tell a detailed story about what it means relative to every other word in the input and how they relate. [[note(right, type:relative, orient:horizontal)]]{}{The LM head is actually interchangeable. We could just as easily replace it with a classification head that will give us a binary yes/no on if the sequence is spam, or a regression head that maps that final vector to a number from 0-100 to tell us how angry a customer was for sentiment analysis.}  We put this single vector through an output layer called the Language Modeling (LM) head. Just like the final output layer in a neural network we described earlier, this LM head simply takes the vector passed into it and map it against the dictionary of words that the model recognizes. This creates probabilities for every word in the dictionary, so we can choose one to be our next word. We then repeatedly add the word we choose to the end of our input sequence and go through the entire sequence of transformer blocks again until we reach the end of the sequence.

[[bigbreak]]
### The KV Cache
[[tab]] There is one glaring inefficiency in this computation: we go through the entire transformer doing work for every single word in the input sequence for every single new word we want to generate, but most of the work we are doing is redundant. This is because during training and inference we apply causal masking, words are only allowed to look at other words that are in front of them. When considering "The fluffy dog barked", "fluffy" is only allowed to look at "The" and "fluffy", it doesn't make sense to give words knowledge of the future. This means that we don't care about the queries those words broadcast anymore. Because of this, in practice when working with transformers we maintain a KV cache.
[[break]]
[[tab]] The concept is simple, every time we generate a new word we append its K and V vectors to a cache, forming two matrices that grow for every new word we process. When a new word goes through the pipeline, we just have to multiple its Q vector by the entire cached K matrix to generate attention scores and add the weighted V matrix. This saves us on having to do a matrix multiplication of the entire matrix of queries by the entire matrix of keys every time we want a new word, reducing it to a much cheaper matrix-vector operation. 

[[bigbreak]]
### Attention Heads
[[tab]] One last topic we need to touch on that is fundamental to modern LLMs is the concept of attention heads. We talked about attention produces enriched context vectors, but in practice we find that it isnt perfect at capturing relationships. It often ends up producing a washed out blend of all of the words that were important to the word being attended to because it may find multiple words equally important but with different reasons.
[[break]]
[[tab]] The solution to this is to split attention up into multiple heads that can all learn different concepts. For example, if we are working with a latent space in $\mathbb{R}^{4096}$ then we may have 32 attention heads that each works in $\mathbb{R}^{128}$. This gives us 32 distinct $W^Q$, $W^K$ and $W^V$ matrices that all have their own independent set of learned weights for every single transformer layer. The heads naturally evolve to learn different geometric concepts; one head may solely try to look for the agent noun that drives some action, another may strictly look for the noun being acted on, another searches for modifiers, etc. 
[[break]]
[[tab]] Once we have all of our new context vectors after multi-headed attention, we stack them all together and multiply by a new output matrix $W^O$. This matrix smooths out the "seams" of where we glued all of the individual attention matrices to blend them into a single coordinate we can pass into the feed-forward network. The output matrix does a couple of things, it resolves all of the disjoint information produced by each individual head, rotates the concatenated vector back into the standard coordinate system of the latent space so teh network will recognize it, and it may amplify insights from some heads while dampening others to reduce any noise in the output.
