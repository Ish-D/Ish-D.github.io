# Layout test

[[summary]]{One page to try the editor on: two columns, a drawing set into the seam between them with the text curving around it, and a few notes in the margins.}

[[drawing(drawings/moon.svg, place: gutter, width: 220, height: 220, wrap: circle, pad: 18, caption: Moon over water, dy[[drop(T)]]he foreword to a book is the part written last and read first. It has to say what the pages could not, in a voice that sounds as though it never struggled to find one. Most of what makes it good is what it leaves out: a few plain sentences, set with care, on a page that has room to breathe.[[note(right)]]{}{Click here, in the margin, and the note opens where it stands. A typewritten page earns its calm from limits. There is one typeface, one size and one measure, and a margin that stays the same all the way down. Nothing competes with the line. When a figure does appear, it is placed the way a printer would place it, with the text given space to turn around it instead of running over it.

This page sets its text in two columns so the seam between them can hold the drawing. The words bend away from the circle line by line, and each line is still set as part of a whole paragraph, so the gaps stay even and the right edge stays quiet.

Try the editor on it. Switch editing on, then click any paragraph to see its source set in the same type. Hover the drawing to move it, change how the text wraps it, or resize it from the corner. Everything you do is written back into the page as plain text.[[note(left)]]{}{A second note, on the left. Dropped next to its paragraph it follows the text; dropped further away it stays where you put it.}

The last thing the foreword usually does is thank people, briefly, and then get out of the way. This one does the same.
